# MOBPROG-IT252-react-w3schools

A coursework repository for **MOBPROG-IT252** containing React exercises and examples based on the [W3Schools React Tutorial](https://www.w3schools.com/react/).

## Tech Stack

- [React](https://react.dev/) (v19)
- [Vite](https://vite.dev/) (v8)
- [Oxlint](https://oxc.rs/)

## Project Structure

```text
MOBPROG-IT252-react-w3schools/
├── my-react-app/       # React + Vite application
│   ├── public/
│   ├── src/
│   ├── index.html
│   ├── package.json
│   └── vite.config.js
└── README.md
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/BluPizarra/MOBPROG-IT252-react-w3schools.git
   cd MOBPROG-IT252-react-w3schools/my-react-app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

### Other Scripts

- `npm run build` — Build the app for production
- `npm run preview` — Preview the production build locally
- `npm run lint` — Run Oxlint

## Branches

Exercises and activities are organized into feature branches:

| Branch | Topic |
| --- | --- |
| `main` | Base React + Vite setup |
| `feature/es6_array` | ES6 Array methods |
| `feature/jsxintro` | JSX introduction and expressions |
| `feature/reactcomponents` | React components and props |
| `feature/reactpropschildren` | React `props.children` |
| `feature/reacthooks` | React Hooks (`useState`) |
| `feature/personalprofile` | Personal profile activity |
